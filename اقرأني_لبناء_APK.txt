مصمم الصفحات - مشروع Android APK

هذا المشروع يحوّل نسخة HTML من مصمم الصفحات إلى تطبيق أندرويد يعمل دون اتصال بالإنترنت.
التصميم المحفوظ يبقى في مساحة تخزين التطبيق على نفس الهاتف.

البناء باستخدام Android Studio:
1. فك ضغط الملف.
2. افتح Android Studio واختر Open ثم اختر مجلد PageDesigner (المجلد الرئيسي للمشروع).
3. انتظر انتهاء Gradle Sync.
4. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5. ستجد ملف APK داخل:
   app/build/outputs/apk/debug/app-debug.apk

البناء عبر GitHub:
1. ارفع جميع محتويات هذا المشروع إلى المستودع، وليس ملف ZIP وحده.
2. افتح تبويب Actions.
3. اختر Build APK ثم Run workflow (أو ادفع تحديثاً إلى فرع main).
4. بعد انتهاء العملية افتح نتيجة التشغيل ونزّل Artifact باسم page-designer-apk.
5. فك ضغط Artifact وستجد app-debug.apk.

ملاحظات:
- هذا APK تجريبي (Debug) للتثبيت الشخصي، وليس إصداراً منشوراً على المتجر.
- لا يحتاج المشروع إلى اتصال إنترنت لتشغيل المصمم نفسه.
- روابط واتساب/الروابط الخارجية تفتح خارج التطبيق.
- لا تحذف بيانات التطبيق أو التطبيق نفسه إذا أردت الاحتفاظ بالتصميم المحفوظ.
